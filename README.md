# The Auction Room Bangladesh Website

A free static website designed for GitHub Pages.

## Files
- `index.html` — website content
- `styles.css` — black and gold responsive design
- `script.js` — mobile menu and scroll animation

## Before publishing
Open `index.html` and replace:
- `Add Channel Link` with your YouTube URL
- `Add Group Link` with your Facebook group/page URL
- `your@email.com` with your real business email
- Replace the TAR text logo later with your actual logo image if desired

## Publish on GitHub Pages
1. Create a GitHub account at github.com.
2. Click **New repository**.
3. Name it `tar-bangladesh`.
4. Make it **Public** and click **Create repository**.
5. Upload all website files to the repository.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Choose branch `main` and folder `/root`, then click **Save**.
9. Your website will be available at:
   `https://YOUR-USERNAME.github.io/tar-bangladesh/`

## Custom domain later
You can connect a purchased domain from the GitHub Pages settings.
