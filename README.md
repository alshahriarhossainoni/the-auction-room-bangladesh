# TAR Bangladesh Website V2

## Upload to GitHub
Upload all files and the `assets` folder to your repository root:
- index.html
- styles.css
- script.js
- market-data.json
- assets/logo.jpg
- assets/founder.jpg

## Update daily market outlook
Open `market-data.json` on GitHub, click the pencil icon, change the values, then commit changes. GitHub Pages will update automatically.
